# Final Light Glass Conky Dashboard

This version avoids Conky's opaque window background entirely.

It uses:
- transparent Conky window
- a semi-transparent light rounded PNG card
- dark text rendered over the card
- centered placement
- automatic Day 1–30 schedule
- desktop notifications

Install:
```bash
cd ~/Downloads
tar -xzf conky-study-dashboard-final.tar.gz
cd conky-study-dashboard-final
./install.sh
```

If Conky is already running, the installer stops it first.
